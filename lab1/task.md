# Lab1 | Типы данных и условные конструкции
### Реализуйте программы в соответствии с требованиями
1. На вход подается дробное число X. Программа округляет X до ближайшего целого числа: [0.0; 0.5) -> 0, [0.5; 1.0) -> 1. Полученное значение выводится на экран.
> Указание: используйте условные конструкции.

    Пример:
    | Входные данные  | Выходные данные |
    | --------------- |-----------------|
    | 1.4             | 1               |
    | 2.5             | 3               |
    | -7.8            | -8              |

---

2. Выполните задачу из пункта 1, не используя условные конструкции и сторонние библиотеки. Разрешается использовать функции ввода/вывода, преобразование типов данных и арифметические операции.
