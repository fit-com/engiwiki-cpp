# Lab1 | Типы данных и математические операции
### Реализуйте программы в соответствии с требованиями

1. Земля состоит из четырех основных слоев: внутреннее ядро (19% от радиуса планеты), внешнее ядро (35.5%), мантия (45%) и кора (0.5%). Будем называть планету землеподобной, если у нее также имеются эти 4 слоя и они сохраняют такое же соотношение с радиусом.
![](https://moya-planeta.ru/upload/images/xl/26/ab/26ab6a2654afaac38f00ef0d373d6143e73ec01a.png)
На вход программе подается положительное целое число R - радиус некоторой землеподобной планеты. Программа выводит целую часть объема мантии этой планеты (принимаем планету за идеальный шар; объем шара вычисляется по формуле: $V = \frac{4}{3}\pi R^3$). Число π считайте равным 3.14.

---

2. На вход подается дробное число X. Программа округляет X до ближайшего целого числа: [0.0; 0.5) → 0, [0.5; 1.0) → 1. Полученное значение выводится на экран.
> Указание: НЕ используйте условные конструкции. Разрешается использовать только функции ввода/вывода, преобразование типов данных и арифметические операции.

Пример:
| Входные данные  | Выходные данные |
| --------------- |-----------------|
| 1.4             | 1               |
| 2.5             | 3               |
| -7.8            | -8              |
